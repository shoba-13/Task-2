# Matrix Operations Using 2D Arrays and Functions in C

This project is developed as part of the CodeAlpha C Programming Internship – Task 2. The main objective of this project is to perform basic matrix operations using the C programming language.

A matrix is a collection of numbers arranged in rows and columns. In this project, two 2×2 matrices are used to perform three important mathematical operations: matrix addition, matrix multiplication, and matrix transpose.

The program uses two-dimensional arrays to store matrix elements. The user can enter the elements of the first and second matrices through the keyboard. The program then processes the entered values and displays the results.

**The project includes three main operations:**

1. **Matrix Addition:** Adds the corresponding elements of two matrices and displays the resulting matrix.

2. **Matrix Multiplication:** Multiplies two matrices using nested loops and calculates the resulting matrix.

3. **Matrix Transpose:** Converts the rows of the first matrix into columns and the columns into rows.

To make the program simple and organized, separate user-defined functions are used for each matrix operation. Nested for loops are used to access and process the matrix elements.

**Concepts Used:**

- C Programming Language
- Two-Dimensional Arrays
- User-Defined Functions
- Nested For Loops
- Standard Input and Output
- Basic Mathematical Operations

**Learning Outcomes:**

Through this project, I learned how to declare and initialize two-dimensional arrays, accept matrix elements from users, perform mathematical operations, and use functions to organize a program. I also improved my understanding of nested loops and logical thinking.

This project helped me gain practical experience in C programming and understand how arrays and functions work together to solve mathematical problems.

**Conclusion:**

The Matrix Operations project is a beginner-friendly C programming application that demonstrates the use of 2D arrays and functions. It provides a simple way to perform basic matrix calculations and strengthens fundamental programming skills.
